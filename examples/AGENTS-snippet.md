# 可选的 AGENTS.md 入口规则

安装后由使用者自行将下面这段合并到适用的全局或项目规则，不自动覆盖原文件。不要提交带个人绝对路径的规则。

```markdown
## 产品与代码协作

产品功能定义、竞品调研、交互/UI 调整、实际功能实现、重构、运行配置/依赖变更和 bug 修复，使用 `$full-stack-product-manager`（全栈产品经理）。

先读取已安装的主 SKILL.md，再按任务阶段读取对应内部模块；只读检查可直接进行，任何交付代码、样式、配置、测试或隔离展示写入前先展示具体方案和彩色流程图，等用户明确确认。每次修 bug 也必须先诊断、提交修复方案、确认后修改。

同一任务的后续消息沿用方案和轮次，不重新启动流程。每次面向用户的回复附阶段、方案及批准状态、是否改代码、本次新增/累计轮次、验证和遗留问题数量。普通翻译、闲聊和非产品文档编辑不触发本规范。
```

此规则提高自动调用的一致性，不是程序级拦截器。未安装 skill 时应说明缺失，不假装加载成功。
